## Latest projects
### AI Travel Planner - https://ai-travel-planner-blsx.onrender.com/
A full-stack web app that turns a few trip preferences (destination, dates, budget, travel style, interests) into a day-by-day itinerary generated by Google Gemini. The user can then edit the plan and keep track of the budget.

### File Storage - https://securesstorage.netlify.app
A full-stack application that allows users to upload, manage and preview files in the cloud. Integrated Cloudinary for file storage and MongoDB for metadata management, supporting images, documents, audio, and video formats with file size validation.  Implemented server-side search, sorting, filtering by file type, and pagination using optimized MongoDB queries and debounced search requests.
